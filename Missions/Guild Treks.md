[Guild Treks](https://wiki.guildwars2.com/wiki/Guild_Trek) are missions that require locating a marker on the ground in various locations. Though best done in groups of 3-6, **all** Treks can be completed solo with the right preparation. Using the [[Guild Trek Organizer]] will dramatically improve the process, though it should be considered a hard requirement to use a pathing module through BlishHUD, TaimiHUD, or a compatible TacO pathing tool. The waypoints in the [[Guild Trek Organizer]] have been tuned to *Lady Elyssa's* pathing module. *Tekkit's* can work, too, though a couple of waypoints might be different. Use the following messaging to gather and instruct players:

### Announcement
Use this announcement if running this outside of a typical run of guild missions:

```
Can I get 3-6 volunteers to help with a Guild Trek mission? REQUIREMENTS: all Core Tyria waypoints AND BlishHUD or similar pathing tool.
```

### Requirements
It's important to confirm that all squad members have a pathing tool. This method really just doesn't work without it.

```
A pathing module is a hard requirement for this mission. While you can certainly use the wiki page to find the locations, it will just slow things down - we going for SPEED.
```

```
Please take a moment to confirm you have a pathing module active through BlishHUD, TaimiHUD, Burrito, etc. I prefer using Lady Elyssa's marker pack for Treks, but you can use Tekkit's, too.
```
